# MindMirror — MCA Minor Project

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- HTML Canvas

## How to run in Visual Studio Code

1. Install Visual Studio Code.
2. Open the `MindMirror` folder.
3. Open `index.html`.
4. Either:
   - Double-click `index.html` / open it in Chrome, OR
   - Install the **Live Server** extension in VS Code.
5. Right-click `index.html` → **Open with Live Server**.

No database, server, npm, or API is required.

## Features
- Daily mood check-in
- Five mood choices
- Energy level slider
- Reasons affecting mood
- Personal reflection text
- Mirror Mode insight generation
- Average energy calculation
- Most frequent mood
- Check-in streak
- Seven-day energy chart
- Reflection diary
- LocalStorage persistence
- Responsive design
- Dark mode based on system preference
